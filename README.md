# 信息科技教学管理系统 - 教师端

一款基于 Flutter 开发的 Windows 桌面应用程序，用于信息科技课程的教学管理，包括题库管理、学生管理、成绩统计、打字练习控制等功能。

## 🎯 功能介绍

### 1. 首页（Dashboard）

首页是教师端的核心控制面板，提供班级与题库的快速管理：

| 功能 | 说明 |
|------|------|
| **班级选择** | 支持初一、初二、初三三个年级，每年级最多20个班级 |
| **题库选择** | 从本地题库目录选择要使用的题库 |
| **同步功能** | 将选定的班级和题库同步到学生端 |
| **学生状态监控** | 实时显示学生状态：在线、离线、打字、小测 |
| **课表自动选班** | 根据当前时间和课表自动选择对应班级 |
| **刷新功能** | 手动刷新学生状态数据 |

**智能同步逻辑**：
- 如果当前班级有学生在线 → 仅同步题库，不修改学生数据
- 如果当前班级无学生在线 → 同步班级和题库配置

---

### 2. 出题（Questions）

题库编辑与管理模块，支持多种题型：

#### 支持的题型

| 题型 | 说明 |
|------|------|
| **选择题** | 四选项单选题，支持题干图片和选项图片 |
| **连线题** | 左右配对匹配题，支持图片配对 |
| **顺序题** | 排序题，将项目按正确顺序排列 |
| **打字题** | 中文/英文打字练习题 |

#### 题库管理功能

- 创建、编辑、删除题库
- 设置考试时间限制
- 设置提前交卷时间
- 支持图片上传与管理（题干图片、选项图片）
- 题目预览与编辑
- 批量题目管理

#### 图片功能

- 支持上传图片到题库
- 图片预览功能
- 图片删除与替换
- 图片自动命名与存储

---

### 3. 统计（Statistics）

成绩统计与分析模块，提供多维度的数据可视化：

#### 统计类型

| 类型 | 说明 |
|------|------|
| **课堂小测** | 小测成绩统计，包括得分、正确率、错题分析 |
| **中文打字** | 中文打字速度、准确率统计 |
| **英文打字** | 英文打字速度、准确率统计 |

#### 统计功能

- **概览卡片**：参与人数、平均分、最高分、最低分
- **分数段分布图**：10分一段的柱状统计图
- **学生排名表格**：可按姓名或得分排序
- **日期范围筛选**：支持自定义日期范围查询
- **班级错题汇总**：查看全班错题情况
- **个人错题详情**：点击学生查看具体错题

#### 数据展示

- 分数段颜色标识（红色-橙色-蓝色-绿色）
- 实时刷新统计数据
- 支持按题库筛选成绩

---

### 4. 学生端控制（TypingControl）

控制学生端打字练习参数配置：

#### 打字配置

| 参数 | 说明 |
|------|------|
| **时间限制** | 打字练习的时间限制（分钟） |
| **满分字数** | 达到满分需要完成的字数/字符数 |
| **目标速度** | 目标打字速度（字/分钟） |
| **每错扣分** | 每个错误扣除的分数 |
| **文章选择** | 随机文章或指定文章 |

#### 中文打字配置

- 时间限制：默认 5 分钟
- 满分字数：默认 100 字
- 目标速度：默认 20 字/分钟
- 每错扣分：默认 1 分

#### 英文打字配置

- 时间限制：默认 5 分钟
- 满分字符：默认 500 字符
- 目标速度：默认 100 字/分钟
- 每错扣分：默认 0.2 分

#### 课表管理

- 周一至周五课程安排
- 每天最多 8 节课
- 可编辑课程时间
- 可为每节课分配班级
- 课表保存与加载

### 5. 学生管理（StudentManagement）

学生与班级信息管理模块：

#### 学生管理 Tab

| 功能 | 说明 |
|------|------|
| **学生信息** | 姓名、密码、电脑名称、IP地址、积分 |
| **添加学生** | 新增学生到指定班级 |
| **编辑学生** | 修改学生信息 |
| **删除学生** | 从班级移除学生 |
| **班级切换** | 将学生转移到其他班级 |

#### 班级管理 Tab

- 查看所有班级列表
- 显示每个班级的学生人数
- **班级升级功能**：
  - 初一 → 初二
  - 初二 → 初三
  - 初三为最高年级，无法升级
- 升级时自动迁移所有学生数据

#### 积分兑换 Tab

- 创建兑换商品（名称、所需积分、库存）
- 查看兑换记录
- 按日期筛选兑换记录
- 积分扣除与库存更新

## 🚀 安装与运行

### 环境要求

- Flutter SDK（Dart SDK 满足 `pubspec.yaml` 中 `>=3.0.0 <4.0.0` 的约束）
- Windows 10/11；运行 Windows 桌面目标需安装并配置 Visual Studio 的 Desktop development with C++ 工作负载
- Git（克隆项目时需要）

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <项目地址>
   cd teacher
   ```

2. **安装依赖**
   ```bash
   flutter pub get
   ```

3. **运行应用**
   ```bash
   flutter run -d windows
   ```

4. **打包发布**
   ```bash
   flutter build windows
   ```

首次构建 Windows 桌面应用前，可运行 `flutter doctor -v` 检查 Flutter、Windows 桌面工具链是否就绪。应用启动时会尝试启动 HTTP 与 Socket 服务；若端口被占用或服务启动失败，桌面界面仍会打开，但学生端连接及同步功能可能不可用。

### 打包后的应用位置

```
build/windows/x64/runner/Release/
```

## 💾 数据存储

### 数据存储方式

班级、成绩、错题、课表、题库和打字文章等业务数据以 JSON 文件形式保存。开发环境的数据目录包括项目根目录下的 `information/` 和 `题库/`；实际运行时的读写位置由应用路径工具根据运行环境确定。发布后请备份应用数据目录，升级或迁移应用时不要只复制可执行文件。

### 班级数据结构

每个班级目录包含：

| 文件 | 说明 |
|------|------|
| `use_list.json` | 学生名单（姓名、密码、电脑、IP、积分） |
| `小测成绩表.json` | 小测成绩记录 |
| `错题记录.json` | 学生错题记录 |

### 题库数据结构

每个题库目录包含 `题库.json` 文件，存储：
- 题目列表
- 题目类型
- 题干与选项
- 图片引用
- 考试配置（时间限制、提前交卷时间）

## 🔌 API 服务

### HTTP API（默认端口 20020）

应用启动时自动尝试启动本地 HTTP API 服务，供学生端获取题库、班级及配置数据并提交登录、成绩等信息。以下为主要接口示例，完整接口以 `lib/services/http_server_service.dart` 中的路由定义为准：

| API | 说明 |
|-----|------|
| `POST /api/active-class` | 设置活跃班级 |
| `POST /api/active-bank` | 设置活跃题库 |
| `GET /api/schedule` | 获取课表 |
| `POST /api/schedule` | 保存课表 |
| `GET /api/typing-config` | 获取打字配置 |
| `POST /api/typing-config` | 保存打字配置 |

### Socket 服务（默认端口 20021）

用于与学生端建立实时通信：
- 学生上线/下线通知
- 实时状态同步
- 打字进度监控
- 小测状态同步

HTTP 与 Socket 服务在应用启动时分别初始化。启动失败不会阻止教师端界面运行，但依赖这些服务的学生端联网功能将不可用。端口配置位于 `lib/config/app_config.dart`。

## 📝 使用说明

### 日常使用流程

1. **启动应用** → 自动根据课表选择当前班级
2. **选择题库** → 选择本节课要使用的题库
3. **点击同步** → 将题库同步到学生端
4. **监控状态** → 在首页查看学生在线状态
5. **查看统计** → 课后查看学生成绩与错题

### 班级升级操作

1. 进入「学生管理」→「班级管理」
2. 选择要升级的班级
3. 点击「升级到 XX」按钮
4. 确认升级操作
5. 系统自动迁移学生数据并删除原班级

### 题库创建流程

1. 进入「出题」页面
2. 选择或创建新题库
3. 选择题目类型
4. 填写题目内容（可上传图片）
5. 设置考试时间
6. 保存题库
